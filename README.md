# bar_scene_client

Клиентская часть многопользовательской 3D-сцены бара: React + TypeScript + Three.js (`@react-three/fiber`, `drei`), обмен данными с сервером через SignalR.

Пример работы: [t.me/koshelenok3d/35](https://t.me/koshelenok3d/35)

## Что делает

- Загружает 3D-модель бара из `public/scene_to_glb_16.glb` и рисует её: пол, стены, мебель, лампы.
- По клику по полу задаёт точку назначения, и персонаж (пока — жёлтый параллелепипед) идёт к ней.
- Обходит препятствия: перед движением проверяет стены рейкастами и выбирает свободное направление.
- Отправляет свою позицию на сервер и принимает позиции других игроков, отображая их фигурки в реальном времени.
- Подключается к SignalR-хабу по WebSocket (`useSignalR.ts`, адрес по умолчанию `ws://localhost:5201/chatHub`, переопределяется через `REACT_APP_HUB_URL`).

## Состав

- `src/App.tsx` — сцена, освещение, синхронизация позиций.
- `src/SceneV2.tsx` — загрузка модели, меши окружения и невидимая геометрия коллизий.
- `src/Character.tsx` — движение персонажа к цели с объездом препятствий.
- `src/Lamp.tsx` — источники света.
- `src/useSignalR.ts` — создание и обслуживание подключения к хабу.
- `src/Chat.tsx` — заготовка текстового чата, в основной сцене пока не используется.

## Запуск

Клиент подключается к серверу `bar_scene_ws_server`, который должен быть запущен отдельно.
