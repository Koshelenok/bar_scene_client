# bar_scene_client

Клиентская часть многопользовательской 3D-сцены бара: React + TypeScript + Three.js, связь с сервером через SignalR.

Пример работы: [t.me/koshelenok3d/35](https://t.me/koshelenok3d/35)

## Возможности

- Трёхмерная сцена бара с мебелью, светом и тенями.
- Управление персонажем кликом по полу: персонаж идёт к выбранной точке и обходит препятствия.
- Совместное присутствие: другие участники видны в сцене и двигаются в реальном времени.
- У каждого участника свой стабильный цвет персонажа, который не меняется при перезагрузке.
- Комнаты: несколько независимых компаний могут находиться в одной сцене, не видя друг друга.
- Ссылка на комнату: адрес вида `?room=<uuid>` можно скопировать и отправить другим. Если UUID в адресе нет, он создаётся автоматически.
- После перезагрузки страницы участник возвращается в комнату и появляется на том же месте, где был.
- Голосовой чат с микрофона: кнопка включения/выключения, звук слышен только участникам своей комнаты.
- Громкость голоса зависит от расстояния между персонажами: рядом — 100 %, при удалении звук плавно стихает.
- Устаревшие комнаты и «пропавшие» участники автоматически убираются, поэтому сцена не засоряется призраками.

## Комнаты

Комната определяется UUID в адресе страницы. Достаточно открыть ссылку с нужным `?room=...` — все, кто её откроет, окажутся в одной комнате. Разные комнаты полностью изолированы друг от друга.

История комнаты хранится ограниченное время (около часа), после чего автоматически удаляется.

## Голосовой чат

- Микрофон включается отдельной кнопкой и только по явному действию пользователя.
- Голос передаётся напрямую между браузерами по WebRTC; сервер используется только для установления соединения.
- Для работы через интернет используются бесплатные публичные STUN-серверы. Собственный TURN-сервер не требуется, но при сложном NAT у обоих участников соединение может не установиться.
- Громкость собеседника плавно снижается по мере удаления персонажей друг от друга.

## Требования и запуск

- Современный браузер с поддержкой WebGL и WebRTC.
- Для микрофона нужен защищённый контекст: `localhost` подходит, при открытии по IP с других устройств необходим HTTPS.
- Рядом должен быть запущен сервер `bar_scene_ws_server`.
- Адрес хаба по умолчанию — `ws://localhost:5201/chatHub`; при необходимости он переопределяется переменной окружения `REACT_APP_HUB_URL` при сборке.

```bash
npm install
npm start     # режим разработки, http://localhost:3000
npm run build # production-сборка
```
